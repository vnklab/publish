# VNK Publisher — онлайн

Страница https://vnklab.github.io/publish/ — публикация роликов на площадки с любого устройства.
Сама страница не хранит ключей: ролик уходит в закрытый репозиторий, публикацию выполняет GitHub Actions,
ключи площадок лежат в зашифрованных секретах. Токен GitHub хранится только в вашем браузере.
