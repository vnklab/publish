Доступ к GitHub

Страница работает через ваш закрытый репозиторий: кладёт туда ролик и запускает публикацию на серверах GitHub. Токен хранится только в этом браузере.

  1. Откройте github.com → Fine-grained token.
  2. Repository access → Only select → vnklab/vnk-publisher-engine.
  3. Permissions: Contents — Read and write, Actions — Read and write, Secrets — Read-only (чтобы видеть, какие площадки настроены).
  4. Срок — 1 год. Скопируйте токен сюда.
